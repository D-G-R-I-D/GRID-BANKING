# Security

GRID is a student project, not a live financial service. Still, if you find a
vulnerability:

- **Don't open a public issue.**
- Use GitHub's **"Report a vulnerability"** button on the repo's Security tab,
  or message the maintainer.
- Don't include real personal or financial data in your report.

## What we care about

- Authentication and session handling
- Anything that lets one user see or move another user's money
- Secrets or tokens reaching the browser
- Security-header / CSP regressions

## Out of scope

- Issues needing a compromised device or browser
- Scanner output with no demonstrated impact
